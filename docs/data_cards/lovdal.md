## Known issues
- Healthy days close to an injury were removed by the authors, so no model is ever asked to score the run-up to an injury; scores may overstate real daily use.
- Column order (authors' README v2): day file suffix .6 = the day before the event, week file without suffix = the week before; the loader orders both oldest -> newest, verified on the data itself.
- -0.01 in the three perceived-effort columns means a rest day; kept as a value, with a rest-day mask.
- Injury = the runner's own log entry 'unable to complete the session due to injury', not a medical diagnosis.
- One team; fewer women than men.
